# D2 Survivors 繁中翻譯規範

遊戲：D2 Survivors，以暗黑破壞神 II 為題材的 survivors-like 網頁遊戲。字典以英文原句為 key，遊戲比對時不分大小寫。

## 輸出格式
- 每批輸入 `i18n/todo/<批名>.json`：`[{"k": 英文 key, "ko"?: 韓文版譯文（只在有佔位符時附上，當作佔位符位置的參考）}]`
- 輸出 `i18n/done/<批名>.json`：一個 JSON 物件 `{ "<英文 key 原樣>": "<繁中譯文>" }`，**每個 key 都要有**，key 一字不改（含大小寫、標點、前綴 `affix:` 等）。
- 用 Write 工具寫檔，寫完跑 `node tools/verify-batch.mjs <批名>`，有錯就修到通過。

## 硬規則（腳本會擋）
1. 繁體中文（台灣用語）。不得出現諺文。不得留空。
2. 佔位符：key 裡的 `#`（數字）與 `*`（任意片段）在譯文中寫成 `{0}`、`{1}`…，依英文出現順序編號；可依中文語序調換位置，但**每個編號都要出現且只出現一次**。有 `ko` 參考時，譯文的佔位符集合必須與 `ko` 相同。
3. ` · `（前後有空格的中點）是遊戲拿來切分的分隔符，譯文中的個數必須與 `ko`／英文相同，原樣保留。
4. 不要加譯註、括號說明、引號包裝。

## 風格
- 術語以 `i18n/glossary.json` 為準（有就照用）；沒有的名詞以《暗黑破壞神 II：獄火重生》官方繁中為準，不確定時取台灣玩家常用譯名。
- **官方譯名優先於直覺**：Aura＝靈氣（不是光環）、Stamina＝精力、Energy＝能量、Vitality＝體能、Act＝章（第一章、各章首領，不用「幕」）。審查時覺得「光環比較通順」也不要改，玩家對照的是官方版。
- 介面按鈕看語境，不要照字面：REPORT＝回報問題（錯誤回報，不是舉報）；Build 後面接版本號時＝版本，指角色時＝流派／配置；手把按鍵 Cross／Circle／Square／Triangle＝叉鍵／圈鍵／方塊鍵／三角鍵。
- 職業：Amazon 亞馬遜、Assassin 刺客、Barbarian 野蠻人、Druid 德魯伊、Necromancer 死靈法師、Paladin 聖騎士、Sorceress 魔法使。
- Diablo II → 暗黑破壞神 II；D2R、D2 Survivors、Ko-fi、Discord、Steam 等專有名詞照留英文。
- 按鍵與縮寫保留原樣：`(T)`、`Esc`、`Shift`、`Ctrl`、`DPS`、`MF`、`XP`。數字、`%`、`+`、`×` 原樣保留。
- 全大寫的 key 是按鈕／標題，譯成簡短詞（PLAY AGAIN → 再玩一次）。
- 句子用自然中文，不逐字直譯；標點用全形（，。：；！？「」），但 `·`、`/`、`-` 分隔符保持半形。
- 「You」譯為「你」。不用簡體字、不用中國大陸用語（檔案、資訊、設定、預設、影片，不用文件、信息、設置、默認、視頻）。

## 魔法物品詞綴（`affix:` 前綴）
遊戲會把魔法物品名組成「後綴 前綴 底材」並以空格相接（例：Sturdy Leather Armor of the Fox → `狐之 堅固 皮甲`）。所以：
- 後綴（of the Fox 這類）譯成「X之」的修飾語。
- 前綴（Sturdy 這類）譯成簡短形容詞，不加「的」。
