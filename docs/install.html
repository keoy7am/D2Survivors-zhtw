D2 Survivors 繁體中文

非官方 Chrome 擴充，把 d2survivors.lol 的遊戲翻成繁體中文。

安裝

  1. 把這個資料夾（d2survivors-zhtw）放在不會被刪掉的地方。
  2. Chrome 網址列輸入 chrome://extensions，打開右上角的「開發人員模式」。
  3. 按「載入未封裝項目」，選擇 d2survivors-zhtw 資料夾。
  4. 打開 d2survivors.lol/play，遊戲就是中文了。

Edge 也能用：網址改成 edge://extensions，步驟相同。

圖示上的標記

97正常運作，數字是翻譯覆蓋率（%）。
NEW有新版擴充，按擴充圖示可以看到版本與下載連結（更新方法見下方）。
off你暫時停用了（按擴充圖示可以切換）。
!遊戲大改版，中文顯示機制暫時失效，已自動改回英文，請等新版擴充。

遊戲一般改版時擴充會自動適應：翻譯照常，新加的內容先顯示英文，覆蓋率會稍微下降。

更新到新版

  1. 下載新版 zip，解壓後覆蓋舊的 d2survivors-zhtw 資料夾。
  2. 到 chrome://extensions，在這個擴充上按「重新載入」（圓形箭頭）。

擴充每 12 小時最多一次向 GitHub 查詢最新版本（只是一般的網頁請求，不送出任何個人資料或遊戲紀錄），有新版時圖示會顯示 NEW。手動安裝的擴充無法自動更新，仍要照上面的步驟換新版。

常見問題

  • 想看英文原版？按網站右上角的「EN」；按「繁中」切回中文。
  • 遊戲設定裡的語言顯示「한국어」？那個選項就是繁中，擴充借用了遊戲的韓文語系欄位。
  • 第一次進遊戲畫面閃了一下？擴充正在準備中文顯示，會自動重新整理一次，之後就不會了。
  • 遊戲卡頓？依序試：
    1. Chrome「設定 → 系統 → 使用圖形加速功能」要開啟；網址列打 chrome://gpu，「WebGL」應顯示 Hardware accelerated。
    2. Windows 顯示縮放（桌面按右鍵 → 顯示設定 → 縮放）越大，遊戲要畫的像素越多；筆電 150%～200% 時特別吃力。
    3. 按擴充圖示，在「效能」區按原生效能（解析度 0.75、關閉光照與陰影）；還是卡再按極致效能（解析度 0.5、關閉光照與陰影、畫面上限 60 FPS），再按套用（遊戲頁會重新整理一次）。也可以逐項自己調後按套用：解析度最低 0.25、畫面上限最低 30 FPS。想確認有沒有生效：開 https://d2survivors.lol/play/?perf，左上角會顯示目前解析度與 FPS（確認完改回不帶 ?perf 的網址再玩）。
      • 原生的三項（解析度、光照、陰影）是遊戲作者內建的畫質設定，不影響排行榜。
      • 畫面更新上限不是遊戲內建功能，是擴充在遊戲外部放慢瀏覽器的畫面更新、不改遊戲程式。遊戲速度與排行榜紀錄依遊戲時間計算，目前不受影響；遊戲日後改版若改變計算方式，會再更新說明。
      • 解析度越低畫面越糊，FPS 越低動作越不順；以玩起來順為準，不是越低越好。
  • 桌面版（exe）能用嗎？不行，只支援瀏覽器版。
  • 看到沒翻到或翻錯的字？按擴充圖示的「回報翻譯問題」，會打開 GitHub 的回報表單並自動帶入版本，寫下哪一句、在哪個畫面就好。漏翻很多時，先按「匯出漏翻清單」，把下載的檔案拖進表單附上。
